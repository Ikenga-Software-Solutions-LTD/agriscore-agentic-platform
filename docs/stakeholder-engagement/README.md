# AgriScore Guyana Pilot — Stakeholder Engagement Pack

**Prepared by:** Chinedu Jamike, Libertas Alpha Technologies  
**Purpose:** Equip the project team to enter stakeholder meetings with a clear message, a focused request, documented safeguards, and a mechanism for converting discussion into accountable next actions.

## How to use this pack

Do not send the complete pack to every stakeholder. Start with the **Core Meeting Brief**, attach only the relevant partner-specific section if needed, and use the meeting playbook and action kit internally. The aim of a first meeting is a suitable next step—not an overloaded presentation or a request for commitments beyond the stakeholder’s mandate.

## Meeting discipline

Every meeting should use the following pattern:

1. Explain the **controlled pilot** and its non-financial boundary.
2. State the **one stakeholder-specific ask**.
3. Listen for the partner’s mandate, requirements, concerns, and constraints.
4. Confirm what is **agreed**, **not agreed**, and **still unknown**.
5. Close with a **named owner, action, date, and follow-up method**.

> No team member may describe a meeting as a partnership, endorsement, data-sharing agreement, or approval unless this has been explicitly confirmed in writing by the authorised stakeholder.
